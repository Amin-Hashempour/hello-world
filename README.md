# نقطه — خبرخوان محلی بازی

یک خبرخوان فارسی با تم تیره و بنفش برای زومجی، ویجیاتو و گیمفا. فقط Python 3.10 یا جدیدتر لازم است؛ هیچ پکیجی نصب نمی‌شود.

## اجرا

در پوشهٔ پروژه اجرا کنید:

```sh
python3 server.py
```

سپس `http://127.0.0.1:8765` را در مرورگر باز کنید. در ویندوز می‌توانید از `py server.py` استفاده کنید. بازکردن مستقیم فایل HTML برای دریافت اخبار کافی نیست. خروج با Ctrl+C است. برای تغییر پورت: `python3 server.py --port 9000`.

بار اول دکمهٔ بنفش فقط جدیدترین مطلب هر منبع را نشان می‌دهد. بارهای بعد مطالب جدید به فهرست اضافه می‌شوند. سابقه در localStorage همین مرورگر و همین آدرس نگهداری می‌شود؛ پاک‌کردن داده‌های سایت، مرورگر خصوصی یا تغییر پورت سابقهٔ جدا ایجاد می‌کند. فیلترها فقط نمایش را تغییر می‌دهند.

سرور فقط روی دستگاه محلی گوش می‌دهد و RSS منابع را می‌خواند؛ خطای هر منبع جدا نمایش داده می‌شود و وضعیت منبع ناموفق جلو نمی‌رود. دریافت به اینترنت و دسترس‌پذیری RSS سایت‌ها نیاز دارد. اگر بین بررسی‌ها بیش از ظرفیت فهرست RSS خبر منتشر شود، فقط مطالب باقی‌مانده در فهرست قابل دریافت است. فایل APK موجود، ورودی این برنامه نیست.

## بررسی

```sh
python3 -m unittest discover -s tests -v
node tests/test_refresh.cjs
```

دسترسی زنده به سه سایت در محیط ساخت با خطای پراکسی ۴۰۳ مسدود بود؛ دریافت واقعی از منابع در این محیط تأیید نشده است. تست‌ها از نمونهٔ RSS و پاسخ‌های کنترل‌شده استفاده می‌کنند.
